# BaseStorage v0.4.1 release notes

## [0.4.1] - 2026-11-01

### Added

- Search the base. A box in the Base Storage menu narrows the chest list to the chests holding an item, most first, with how many each holds. Highlight makes every match glow.
- A **Mark** button in the menu. While it is on, a left click marks favourites, with no need to hold Alt.
- Favourite items say so in their tooltip.

### Changed

- Favourites now belong to the item, not the slot. Move a stack and the star moves with it, and every stack of that item is protected from Put away and Place stacks. Stars from older versions are carried over the first time you open your inventory.
